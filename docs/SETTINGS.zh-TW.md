# 設定與疑難排解 — 零跑 C11 適配版

[繁體中文首頁](../README.zh-TW.md) · [安裝與連線](INSTALL.zh-TW.md) · [隱私權與診斷](PRIVACY.zh-TW.md)

本頁說明 C11 的目前版本 0.2.20-C11.24。舊版 BYD／DiLink 設定指南不代表這些功能仍適用於 C11。

## C11 相關設定

- **連線：**選擇可用的 USB、車載熱點、Wi-Fi Direct 或現有 Wi-Fi 連線方式；無線探索依韌體和 Android 權限而異。
- **儀表上的 CarPlay 地圖：**在 C11 儀表顯示導航畫面，調整地圖大小、左右位置、上下位置和邊緣漸隱。儲存後重新連線套用，不會立即中斷正在使用的 CarPlay。詳見[C11 地圖版面](C11-MANUAL-MAP-LAYOUT.md)。
- **音樂卡與轉向提示卡：**使用 iPhone 傳來的媒體和導航狀態；空白歌曲資訊或媒體連線中斷時會清除音樂卡。
- **C11 車輛日誌讀取（實驗性）：**位於進階設定，預設關閉。啟用需有已授權的網路 ADB，並在儲存後重新連線。會讀取檔位、電量、車速和方向盤事件，可支援倒車時暫停音樂。一般 CarPlay 不需要 ADB。
- **方向盤媒體控制：**C11 方向盤按鍵以車機廣播送入；實際車輛功能仍待此版本的實車驗收。
- **背景更新檢查：**目前查詢上游 DiPlay，而不是 C11 分支。請在 **設定 → 關於** 關閉，並從本專案 [Releases](https://github.com/w012w012/DiPlay-Leapmotor/releases) 取得更新。

BYD HUD、BYD 電量／輪速／胎壓和氛圍燈功能在 C11 版已移除或停用。不要依照舊指南在 C11 啟用它們。

## 診斷與回報

在 **設定 → 診斷 → 儲存診斷報告** 匯出目前版本報告。請記下故障時間及重現步驟，附上車機／韌體、Android、iPhone／iOS、連線方式和相關設定。公開前檢查報告中的個人資訊；勿附熱點密碼或認證檔案。詳見[隱私與診斷](PRIVACY.zh-TW.md)。
