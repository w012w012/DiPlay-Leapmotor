# 隱私權與診斷 — 零跑 C11 適配版

DiPlay 透過本機連線與 iPhone 使用 CarPlay，不需要帳號或遠端認證服務，也不會自動上傳診斷報告。CarPlay 內各 iPhone 應用程式的網路和隱私行為由其各自負責。

## 車機上的資料

應用程式會在本機儲存設定、配對裝置選擇、配對資料及有限的診斷資訊。Android 備份不包含認證與配對資料。解除安裝會刪除應用程式私有資料；已匯出到其他位置的報告需自行刪除。

診斷報告可能包含應用程式／裝置版本、顯示設定、連線狀態、Wi-Fi 狀態和解碼恢復事件。匯出器會過濾協定內容、憑證及常見識別資訊，但未必能辨識所有廠商自訂文字。公開分享前請先檢查；GitHub 問題頁是公開的。只有在你選擇分享或附加檔案時，報告才會傳送。

Android 9 及更舊版本可能在儲存報告時要求權限。下載資料夾或文件選擇器無法使用時，應用程式會提供外部或私有儲存空間作為替代，確認畫面會顯示檔案位置。舊版 Android 上，取得儲存權限的其他應用程式可能讀取外部報告。解除安裝會刪除私有報告，但不會刪除下載資料夾中的檔案。

## 權限與 C11 車輛日誌

藍牙／附近裝置與 Wi-Fi／位置權限支援裝置探索及無線傳輸。麥克風權限供 Siri 和通話使用。本機 VPN 權限承載 USB 網路連線，不提供遠端網際網路 VPN。

**C11 車輛日誌讀取（實驗性）** 預設關閉。啟用時，DiPlay 透過已授權且可連線的網路 ADB 讀取本機車輛日誌中的檔位、電量、車速和方向盤狀態事件，並可支援倒車時暫停／離開倒車後恢復音樂。此功能不會自行開啟或授權 ADB。關閉即可停止這項選用讀取；變更後請重新連線。一般 CarPlay 不需要此功能或 ADB。

## 網路請求與更新

背景更新檢查目前查詢上游 shihabal3amri/DiPlay 的公開 GitHub Releases，不是此 C11 分支。GitHub 會收到車機的網路請求；未經你的操作不會下載或安裝更新。上游 APK 和 C11 版簽章不同，不能直接覆蓋更新。請在 **設定 → 關於 → 背景更新檢查** 關閉檢查，並使用本 C11 專案的[發行頁面](https://github.com/w012w012/DiPlay-Leapmotor/releases)。
