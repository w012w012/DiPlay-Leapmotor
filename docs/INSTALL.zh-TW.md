# 安裝與連線 — 零跑 C11 適配版

本指南適用於 0.2.20-C11.24。系統指紋包含 qti/msmnile_gvmq 時會啟用 C11 程式；其他 C11 韌體尚未確認。詳見[C11 相容性與限制](COMPATIBILITY.md)。

## 安裝前

1. 停車後，從[本專案 Releases](https://github.com/w012w012/DiPlay-Leapmotor/releases)取得 APK，安裝在 Android 車機，不要安裝到 iPhone。若沒有適用版本，請參閱[建置指南](BUILD.zh-TW.md)。
2. 本分支與上游 DiPlay 套件名稱相同，但簽章不同，無法直接覆蓋更新。解除安裝會刪除應用程式私有設定和配對資料，請先備份需要的資料。
3. 開啟 DiPlay，依連線方式授予所需權限。無線探索可能需要藍牙／附近裝置和 Wi-Fi／位置權限；Siri 與通話使用麥克風。USB 連線可能要求本機 VPN 權限，以承載 USB 網路連線；這不是網際網路 VPN。
4. 連線前請關閉其他手機投影應用程式。

應用程式的背景更新檢查目前查詢上游 DiPlay，而非本 C11 分支。請到 **設定 → 關於 → 背景更新檢查** 關閉，再從本專案 Releases 檢查 C11 更新。

## 無線連線

依車機和 DiPlay 提供的方式選擇：

- **車載熱點：**讓 iPhone 和車機透過車載熱點連線。保持 iPhone 的 Wi-Fi 和藍牙開啟，依提示與車機配對並連線。
- **Wi-Fi Direct：**須由車機韌體支援；可用性和頻段行為依 Android 版本與韌體而異，參閱[Wi-Fi Direct 限制](ANDROID9_WIFI_DIRECT.md)。
- **現有 Wi-Fi／同一區域網路：**將 iPhone 和車機連到同一台路由器或隨身 Wi-Fi，並關閉用戶端隔離。DiPlay 不會替你修改路由器或加入網路。

一般 CarPlay 不需要 ADB。**C11 車輛日誌讀取（實驗性）** 是另一項設定，預設關閉；只有在網路 ADB 已授權且可連線時才能使用。啟用後會讀取檔位、電量、車速和方向盤事件，依日誌事件支援倒車音樂暫停／恢復。變更設定後儲存並重新連線。

## USB 連線

使用支援資料傳輸的 USB 連接埠與傳輸線，選擇 **Connect with USB**，並接受 USB、iPhone 信任／CarPlay 或本機 VPN 提示。僅供充電的連接埠或線材無法使用。

## C11 儀表顯示

C11 版可在儀表顯示 CarPlay 導航畫面。可在 C11 地圖設定調整大小、左右／上下位置和邊緣漸隱。儲存不會中斷目前連線；重新連線後套用。詳見[C11 地圖版面](C11-MANUAL-MAP-LAYOUT.md)。

音樂卡、轉向提示卡和 C11 方向盤媒體廣播仍保留，但目前版本尚未完成完整實車驗收。文件中的 BYD HUD、BYD 車輛資料和氛圍燈說明不適用於此 C11 版本。

## 診斷

遇到連線問題時，請在目前 C11 版本重現，再使用 **設定 → 診斷 → 儲存診斷報告** 匯出報告。記錄故障時間，並附上車機／韌體、Android、iPhone／iOS、連線方式、設定與重現步驟。分享前請檢查報告內容。報告不會自動上傳；勿分享熱點密碼或認證檔案。
